# XSTEP4 toolkit

Welcome to XSTEP4 toolkit version 4.1! The XSTEP4 toolkit was created as an improvement for the previous XSTEP3 toolkit... see [1]  for original XSTEP4 documentation and, for more information about XSTEP3, see [2]. Both toolkits were designed to be easy to used and mimics the NeXTSTEP look and feel on X11. The XSTEP4 major improvement regards to the new library syntax and improved synergy with X11, which includes even transparent backgrounds, as demonstrated in the incomplete, but impressive, XSTEP Window Manager (xstepwm):
